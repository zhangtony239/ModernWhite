# ModernWhite

ModernWhite is a customized light theme for Blender, based on the community [White](https://extensions.blender.org/themes/theme-white/) theme.

Its visual direction takes inspiration from the default light appearance of Windows 11 and Microsoft's modern UI aesthetics, with cleaner neutrals, softer contrast, and a more polished desktop feel.

The goal is to bring a more familiar, modern Windows-style visual language to Blender while keeping the interface clear and practical for everyday use.
